# Badban Decision Log

This directory is the source of truth for accepted Badban product, business, financial, risk, governance, and architecture decisions.

## Rule

From 2026-10-05 onward, material decisions must be recorded in this repository rather than existing only in chat.

Each decision should include:

- status;
- date;
- scope;
- decision;
- rationale;
- consequences;
- superseded decision(s), when applicable.

## Statuses

- **Proposed** — under discussion.
- **Accepted** — approved and active.
- **Superseded** — replaced by a newer decision.
- **Rejected** — considered but not adopted.
