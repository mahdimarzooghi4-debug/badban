# Badban Business

This directory contains the business source of truth for Badban.

## Delivery order

Badban follows the parent product-development process:

**Business → Technical → Scrum/Product Backlog → Sprint → Code → Code Review → Stage → QA/Testing → Release Approval → Production → Monitoring → Improvement**

Technical architecture and implementation must not outrun unresolved business decisions.

## Decision authority

Material product, business, financial, risk, governance, and architecture decisions are recorded in [../decisions](../decisions/README.md).

When an older source document conflicts with an Accepted decision in the repository, the repository decision is authoritative for the evolving Badban product.
